# QUASAR

**QUASAR** — DevTools-расширение для Chrome, которое автоматизирует рутину QA-инженеров: сокращает время на составление баг-репортов с 15–20 минут до 30 секунд.

---

## Для кого :

- QA инженеры и тестировщики
- QA лиды
- Команды разработки

---

## Что умеет (план продукта)

| Фича                 | Описание                                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Bug Capture**      | Одним кликом собирает скриншот, ошибки консоли, упавшие запросы и окружение — и оформляет в готовый баг-репорт |
| **Network Profiles** | Профили фильтрации сетевых запросов для быстрого переключения контекста                                        |
| **Session Recorder** | Запись сессии тестирования без чувствительных данных                                                           |
| **Quick Actions**    | Панель быстрых действий прямо в DevTools                                                                       |
| **Интеграции**       | Jira, YouTrack, Linear, Notion, GitHub, Slack, Telegram                                                        |

## Структура проекта

```
quasar/
├── extension/   Chrome-расширение (Manifest V3, React, Vite) — в разработке
├── backend/     API-сервер (Node.js, Fastify, Prisma, PostgreSQL)
├── web/         Сайт: лендинг + дашборд (Next.js) — в разработке
├── shared/      Общие TypeScript-типы и бизнес-константы
└── docker-compose.yml  PostgreSQL 16 + Redis 7 для локальной разработки
```

---

## Текущее состояние

Проект находится на ранней стадии. Уже готово:

- Монорепо с общей типизацией (`shared/`) — типы сущностей, лимиты планов
- Полная схема базы данных (Prisma): пользователи, подписки, баг-репорты, интеграции, команды и пр.
- Базовый API-сервер: `GET /health`, `GET /health/ready` (проверка БД)
- Docker Compose для локальной инфраструктуры

В разработке: аутентификация, CRUD баг-репортов, UI расширения, лендинг.

## Быстрый старт

```bash
# Поднять PostgreSQL + Redis
docker-compose up -d

# Установить зависимости
npm install

# Применить схему БД и заполнить тестовыми данными
cd backend
npm run db:push
npm run db:seed

# Запустить backend в режиме разработки
npm run dev
```

API будет доступен на `http://localhost:3001`.
